Here are some of my favorite projects:

**[FigManager](https://github.com/johnseagull3326/figmanager)**  
A versatile configuration library with rich data types and automatic JSON saving and loading. It also cleanly handles extensions to seamlessly integrate into various java-based platforms.

**[JIF](https://github.com/johnseagull3326/jif) - (JohnSeagull Image Format; great name, I know)**  
A full image codec with a JavaFX interface. It supports lossless RLE compression as well as lossy color subsampling and pixel merging.

[My Modrinth page](https://modrinth.com/user/r9AU66Ga)  
Where I publish my Minecraft Mods of varying usefulness.  
 
[Soundfonts](https://github.com/johnseagull3326/soundfonts)  
Some home-made soundfonts. So far it's just my piano but might add more of my instruments.
